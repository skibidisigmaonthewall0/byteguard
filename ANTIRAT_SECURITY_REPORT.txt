3. NEXT-GEN COUNTERMEASURES & FEATURE IMPLEMENTATIONS
--------------------------------------------------------------------------------
[1] JNI / Native Shared Object Binary Scanner (JniBinaryScanner.java)
    - Parses embedded .dll, .so, and .dylib files dropped inside resources/ or 
      the JAR root.
    - Scans native binary import tables and raw string tables for malicious 
      native API imports:
      * Remote Downloaders : URLDownloadToFileA/W, WinHttpOpen, InternetOpenUrl
      * Native Shells      : CreateProcessA/W, WinExec, system(), ShellExecute
      * Raw C2 Sockets    : WSAStartup, WSASocket, connect, send, recv
      * Memory Injection   : VirtualAllocEx, WriteProcessMemory, CreateRemoteThread
      * Surveillance       : SetWindowsHookExA/W, GetAsyncKeyState

[2] Custom ClassLoader Subclass & defineClass() Bytecode Trap
    - Traps any class extending java.lang.ClassLoader, java.net.URLClassLoader, 
      or java.security.SecureClassLoader.
    - Flags runtime invocations and reflection calls targeting defineClass(byte[]) 
      that pass raw byte arrays at runtime (+65/+85 score).

[3] Real-Time JVM Behavioral Agent (-javaagent:anti-rat-1.0.0.jar)
    - Includes a built-in premain / agentmain JVM ClassFileTransformer 
      (AntiRATAgent.java) that provides real-time behavioral monitoring during 
      game execution.
    - Intercepts process execution attempts (ProcessBuilder / Runtime.exec), 
      monitors sensitive file reads/writes (.minecraft/options.txt, browser 
      credentials), and audits raw TCP socket connections while the game runs.
